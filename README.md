# PeluangKu — Media Pembelajaran Digital Berbasis Teori Beban Kognitif

Aplikasi web (mobile-first, bisa dibuka di smartphone dan browser laptop) untuk membantu siswa SMP kelas 8 mempelajari materi **Peluang** sehingga kemampuan **literasi matematis** meningkat. Desain aplikasi berpijak pada **Teori Beban Kognitif (Cognitive Load Theory/CLT)**: mengurangi *extraneous load*, mengelola *intrinsic load*, dan mendorong *germane load*.
